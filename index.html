What will change in the CSV export?

Only the four target fields are exported, in a fixed order. Unmapped source columns stay in the original file. Optional ID trimming and spreadsheet-safe apostrophe prefixes are documented in the JSON report. These prefixes alter exported cell text; mapped raw values remain available in the report.

This workspace reviews metadata. It does not correct measurements, identify outliers, or assess experimental validity.
